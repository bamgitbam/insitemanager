Privacy & Security

Private by design. Clear about what we verify.

We build for controlled devices, local work and explicit operator decisions. The protection and connectivity of each capability depend on the application and environment in which it runs.

How we build

Practical protections, built into the workflow.

Our goal is to keep the user in control of devices, evidence and connectivity, with features reviewed for the environments where they will be used.

Local and private-network workflows

Core workflows across these products are designed for local operation. Specific camera streams, maps and optional integrations can have separate network requirements.

  • No mandatory cloud account for the documented local-first workflows.
  • Private LAN and offline field use guide the product design.

Operator-controlled changes

Inspection and configuration changes are different activities. Where supported, device-changing actions use explicit authorization boundaries.

  • Credentials belong in their intended session and application context.
  • Exports and evidence sharing are deliberate actions.

Security checks during development

We use local regression tests, dependency reviews and secret-scanning checks to support controlled changes. Findings remain available for operator review rather than being silently hidden.

  • Redacted local secret-scanning reports with findings retained for operator review.
  • Review-required scan results stay visible; browser, workstation and physical-device verification remain separate.

Public website boundaries

This site uses locally served styles, scripts and imagery, with no added analytics or third-party runtime libraries in this implementation.

  • No application credentials, network inventories or private diagnostic bundles in public assets.
  • Hosting and optional external destinations have their own service policies.
Verification is specific

A successful browser check doesn't establish native-device acceptance. We publish feature stages based on the tests actually completed, and keep open qualification work visible.
